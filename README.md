# Aciona

Aciona organiza os relatos de moradores e a fila de ocorrências dos síndicos. Projeto da equipe Órbita no Orion Bootcamp.

## Página de apresentação

Abra `index.html` no navegador. A página usa HTML, CSS e arquivos locais. Ela pode ser servida diretamente, sem instalação ou compilação.

O site [aciona.techtupa.com.br](https://aciona.techtupa.com.br/) recebe as versões da branch `deploy/aciona`. Para publicar uma mudança já integrada em `main`, abra um pull request de `main` para `deploy/aciona`. Após o merge, confira o commit no histórico da Hostinger e abra a página pública.
